# v1.7.0

- 新增备份结果主动通知功能：
  - 支持下拉选择通知时机：**关闭** / **成功 & 失败** / **仅失败**。
  - 遵循 AstrBot 官方 `unified_msg_origin` 规范，在仪表盘「计划与连接设置 → 消息通知」中通过「选择平台 + 群聊/私聊 + 填群号/用户 ID」可视化添加目标（也支持直接粘贴完整 UMO），并提供「发送测试通知」一键验证。
  - 新增仅管理员可用的 `/backup_notify add|del|list|mode` 指令，可在目标群或私聊中直接绑定与切换通知时机。
  - 通知文案已脱敏，不暴露完整 WebDAV 地址与凭据；通知异常不影响备份主流程。
- 在「备份内容 → 备份 temp 目录」中新增「查看当前大小」按需查询按钮，异步统计 `data/temp` 实际待备份体积与文件数。
- 优化双目标状态卡片主文案语义：统一展示「最近备份时间/结论」，将单次归档大小、耗时或失败原因作为带明确标签的副信息呈现。
