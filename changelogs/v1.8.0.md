# v1.8.0

- 修复拉取 WebDAV 远端备份到本地时遇到 `HTTP 302` 重定向（如 Alist / OpenList / 网盘直链）报错的问题，支持最多 5 跳安全重定向，并在跨域跳转时自动剥离 `Authorization` 凭据头。
- 优化 WebDAV 上传进度展示：上传传输阶段显示 `0% → 99%`，全部字节发送完毕后切换为「等待服务端写入」阶段提示，避免在服务端落盘/转存网盘期间进度条停滞在 `100%` 造成卡死错觉。
- 修复工作区 Tab 栏在部分视口下右侧出现多余垂直滚动条的样式问题。
- 新增「运行日志」Tab，支持按级别（`INFO` / `WARNING` / `ERROR`）筛选、SSE 实时推送、一键复制与清空。
- 精简插件控制台日志：将底层 WebDAV HTTP `started` / `returned HTTP` 与逐条校验/清理细节降级为 `DEBUG`，仅保留高价值的业务级摘要日志。
