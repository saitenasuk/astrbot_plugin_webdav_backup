# v1.5.0

- 重构 WebUI 备份仪表盘为「健康概览 + KPI 指标 + 双目标状态卡 + 多视图标签工作区（运行历史 / 备份文件 / 计划与连接设置）」。
- 新增本地与 WebDAV 自动保留策略（`local_keep_count` / `webdav_keep_count`），备份完成后自动清理超出份数的本插件历史 ZIP，不影响手动上传或原生备份。
- 新增「备份文件」管理标签页：支持本地备份列表查看、`bridge.download()` 直接下载与删除；支持 WebDAV 远端备份列表查看、一键拉取到本地 `data/backups/`（供原生备份恢复）与远端删除。
- 移除 `ASTRBOT_WEBDAV_PASSWORD` 环境变量接管逻辑，WebDAV 密码直接在输入框配置。
- 修复 AstrBot 设置「跟随系统」深色模式时插件仪表盘未同步切换暗色主题的问题。
- 新增 Cron 常用预设与未来 3 次执行时间实时预览，运行历史补充触发方式、耗时、筛选与路径一键复制。
